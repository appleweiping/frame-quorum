# Security policy

## Supported versions

Security fixes are provided for the latest released minor version.

## Reporting

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature on
this repository. Include affected version, reproduction steps, impact, and any suggested mitigation. Expect an
initial acknowledgement within seven days.

## Processing untrusted images

Frame Quorum delegates decoding to Pillow. Keep Pillow current, apply operating-system limits when scanning
untrusted files, and heed Pillow decompression-bomb warnings. Run untrusted workloads as an unprivileged user in a
separate directory. The tool never executes filenames and does not invoke a shell or video decoder. Human-readable
CLI messages escape filename control characters and code points unsupported by the active console encoding.

Frame Quorum converts Pillow decompression-bomb warnings into scan errors and refuses contact-sheet canvases above
50 million pixels. These are defense-in-depth guards, not a substitute for process memory, CPU, file-count, and
input-size limits. Filename timestamp regexes are user configuration and should not be supplied by an untrusted
tenant without an external timeout.

`demo --force` removes only the exact 18 filenames generated by the demo, rejects a symbolic-link frame directory,
and refuses directories containing any other entry. Selection output may overwrite `manifest.json` and
`contact-sheet.png` in the explicitly supplied output directory; that directory must be outside the scanned input
tree. Both artifacts are rendered successfully in a staging directory before either existing artifact is replaced.
The final two filesystem replacements are separate operations; ordinary commit errors trigger a best-effort
rollback to copied prior artifacts. An abrupt process or machine failure between replacements cannot be made atomic
across all filesystems.

Manifests expose relative filenames, timestamps, dimensions, and image-derived measurements. Treat them as
sensitive metadata when input is confidential.
